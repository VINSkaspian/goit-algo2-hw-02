
# goit-algo2-hw-02

Домашнє завдання до модуля «Основи аналізу та алгоритмічні стратегії» (теми 1 та 2).

## Вміст
- `goit_algo2_hw_02.py` — реалізація завдання 1 (divide & conquer min/max) та завдання 2 (жадібна оптимізація для 3D-принтера) разом із простими тестами.
- Запуск: `python goit_algo2_hw_02.py`

## Примітки по реалізації
- **Завдання 1**: рекурсивний підхід (розділяй і володарюй), повертає кортеж `(мінімум, максимум)`, складність `O(n)`.
- **Завдання 2**: стабільний жадібний алгоритм формування партій друку з урахуванням `max_volume` та `max_items`; сортування за пріоритетами (1→3) зі збереженням початкового порядку всередині кожного пріоритету.
